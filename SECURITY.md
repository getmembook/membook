# Security Policy

Membook's core promise includes: **no secret ever reaches a committed memory file.**
Distillation output is secret-scanned before anything is written under `.membook/`.

If you discover a vulnerability — especially anything that could cause credentials,
tokens, or other secrets to be written to a Memfile or `MEMBOOK.md` — please report
it privately to security@membook.dev (interim: via a GitHub security advisory on
this repository). Do not open a public issue for security reports.

We aim to acknowledge reports within 72 hours.
