Membook

Memory that stays true.

Coding agents forget. Worse, they misremember — a note saying “we use Jest” survives the migration to Vitest and gets handed to the next agent as fact. Every agent-memory tool on the market stores text that nothing keeps honest.

Membook anchors each memory to something checkable — a commit, a file, a symbol. When the code moves, the memory knows: it is re-verified, marked stale, or invalidated, and a memory that can no longer be trusted is withheld rather than asserted. 

npx membook init
  • Files are the truth. Memories are markdown committed to your repo — they render on GitHub and get reviewed in pull requests. The index is a disposable cache.
  • No daemon, no network. The MCP server spawns per session and exits with it. Nothing leaves your machine.
  • Honest status. A memory is unverified until something actually verifies it — we would rather show you a thinner book than a flattering one.
